# spending-agent

Маленький агент учёта трат: пишешь одну фразу - он записывает трату в учёт и говорит, сколько осталось от недельного лимита.

```
$ python3 spending_agent.py "продукты 908"
Записала (google/gemma-4-31b-it:free): 25.10 · продукты · 908 ₽ · продукты
Остаток недели: 9 662 из 12 000
```

## Как это устроено

1. **Фраза → модель.** Фраза уходит в языковую модель через [OpenRouter](https://openrouter.ai) (по умолчанию бесплатная модель). Модель возвращает JSON: сумма, категория, короткое описание, «сегодня или вчера». Понимает свободную речь: «вчера такси 899», «возврат за духи 2890».
2. **Запись локально.** Строка добавляется первой в таблицу учёта трат (обычный markdown-файл). Сам учёт **никуда не отправляется** - модели уходит только введённая фраза.
3. **Остаток считает программа, не модель.** Сумма за текущую неделю (пн-вс) по строкам, которые входят в лимит. Обязательные платежи, долги, переводы и строки с пометкой «вне лимита» не считаются; возвраты уменьшают сумму.
4. **Бесплатные модели часто отключаются**, поэтому программа пробует несколько по очереди. **Без ключа, без сети или если не ответила ни одна** работает простой разбор «слово + число», чтобы запись не терялась.

## Запуск

Нужен только Python 3.9+ (без сторонних библиотек).

```bash
# ключ OpenRouter хранится вне хранилища, например в ~/.secrets/openrouter.env
set -a; . ~/.secrets/openrouter.env; set +a

export SPENDING_LOG=~/path/to/spending-log.md   # по умолчанию - examples/spending-log.example.md
python3 spending_agent.py "продукты 908"
```

| Переменная | Что задаёт | По умолчанию |
|------------|-----------|--------------|
| `OPENROUTER_API_KEY` | ключ OpenRouter | нет - тогда разбор без модели |
| `OPENROUTER_MODEL` | модель или несколько через запятую (запасные) | четыре бесплатные (см. `MODELS` в коде) |
| `SPENDING_LOG` | путь к учёту трат | пример из `examples/` |
| `SPENDING_WEEKLY_LIMIT` | недельный лимит, ₽ | 12000 |

> Бесплатные модели в OpenRouter периодически меняются. Ошибка 404 значит, что модели больше нет: выберите новую на [openrouter.ai/models?q=free](https://openrouter.ai/models?q=free).

Тесты: `python3 -m unittest -v`

## Паспорт хранилища

**Класс:** именованный проект (код), открытое хранилище.
**Назначение:** код агента учёта трат и пример с выдуманными цифрами - для себя и как проект в портфолио.

| Данные | Где живут | Чувствительность |
|--------|-----------|------------------|
| Код, README, пример учёта | здесь, открыто | публичные |
| Настоящий учёт трат | вне хранилища, в закрытом личном пространстве | личные финансовые - сюда не попадают |
| Ключ OpenRouter | вне хранилища, `~/.secrets` | секрет - сюда не попадает; CI-проверка на секреты при каждом сохранении |
