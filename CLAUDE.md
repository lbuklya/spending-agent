## Work-Product Gate

Нетривиальная работа (>15 мин) здесь идёт по РП #18 «Агент учёта трат» (DS-strategy, план недели), как и во всей экосистеме IWE - см. `${IWE_WORKSPACE:-$HOME/IWE}/CLAUDE.md` §2.

## Работа с данными

- Хранилище **открытое**. Никогда не класть сюда настоящий учёт трат, суммы и описания из личных записей, ключи и пароли. Примеры - только с выдуманными цифрами (`examples/`).
- Ключ OpenRouter - только через переменную окружения `OPENROUTER_API_KEY`, файл ключа вне хранилища; не называть путь к нему в командах агента.
- Перед сохранением - `python3 -m unittest -v`.
